# -Mangekyou-Sharingan-PCB-Earring-Wearable-Tech-by-Noberto
Where anime meets engineering! 👁️⚡ The Itachi PCB Earring by Noberto is a custom piece of wearable tech. Hand-soldered with 0603 SMD components, it uses optical light diffusion to turn a white board into a glowing red Sharingan in the dark. A true cyberpunk accessory.
